Other Resources

A short, vetted list.

There are hundreds of FTC resources online. Most aren't useful. This is what we open during a build season — organized by what you'd be doing when you reach for it.

CAD & part libraries

When you're modeling.

  • O Onshape
    Free for FTC teams. Browser-based parametric CAD. The CAD platform every example here uses.
     CAD
  • g goBILDA Onshape library
    Every goBILDA part as an Onshape Part Studio. The official source — don't grab CAD from random forums.
     Library
  • R REV Robotics CAD
    REV's parts as Onshape and STEP files. Use the Onshape versions when you can.
     Library
  • P Onshape public documents
    Other teams' robots are public by default. Search before reinventing.
     Reference

Calculators & FeatureScripts

For the math you don't want to redo each season.

  • π JVN design calculator
    A spreadsheet for sizing motors, gear ratios, and lift loads. The de facto FRC tool — works fine for FTC scale.
     Calculator
  • ƒ Slot FeatureScript
    Onshape custom feature for parametric slots. Used in nearly every chassis you'll model.
     FeatureScript
  • Σ Mass properties helper
    Estimate where the center of mass sits before you build. Useful for arm balance.
     FeatureScript

Programming

When the CAD is done and the wires are next.

  • D FTC official documentation
    The canonical reference for the FTC SDK, hardware setup, and the season's rules.
     Docs
  • R Road Runner
    A motion planning library for autonomous paths. Adopted by serious teams; worth the learning curve in year two.
     Library
  • { } FtcRobotController (GitHub)
    The starter project. Fork this; don't try to build from scratch.
     Code

Community

Where to ask, where to read, where to get a design review.

  • # FTC Discord
    The main community server. Channels for design, programming, season strategy, and inspection. The place to ask "is this allowed?" and get a real answer.
     Discord
  • CD Chief Delphi (FTC section)
    Long-form posts, build threads, off-season analysis. Less real-time than Discord; more depth.
     Forum
  • YT Build season vlogs
    A handful of teams post weekly build vlogs. Useful for seeing how design decisions actually shake out across a season.
     Video
Contributing

Add to the library.

FTCDesign is community-built. If you've got a mechanism worth annotating, a handbook entry to write, or a correction to file, the project lives on GitHub. Open an issue or a pull request — both get read.

The bar for contributions: a working example, an opinion attached, and the trade-offs called out. We'd rather have ten well-explained examples than a hundred uncommented ones.

What we don't take

We pass on link dumps, generic CAD tutorials, and seasonal strategy guides. The site stays useful by staying small. Plenty of other places host those resources well; we won't compete.
