Resources

External tools, libraries, and community links worth knowing. Curated, not exhaustive.

CAD & part libraries

  • Onshape — free for FTC teams. Browser-based parametric CAD.
  • goBILDA Onshape library — every goBILDA part as an Onshape Part Studio.
  • REV Robotics CAD — REV's parts as Onshape and STEP files.

Programming

  • FTC official documentation — the canonical reference for the SDK and rules.
  • Road Runner — motion planning library for autonomous paths.
  • FtcRobotController — the starter project on GitHub.

Community

  • FTC Discord — main community server. Channels for design, programming, season strategy, inspection.
  • Chief Delphi (FTC section) — long-form posts and build threads.

Contributing

FTCDesign is community-built. The bar for contributions: a working example, an opinion, and the trade-offs called out. The repo takes issues and pull requests.
