CAD Best Practices

Five articles, read in order.

The point of this section: keep loading times low and stay organized so changes are easy. Conventions that show up here are followed throughout the rest of the site.

In this section

  • 1. Document setup
  • 2. Sub-document setup
  • 3. Layout sketches
  • 4. Part studio practices
  • 5. Assembly practices
  • Self-review checklist

A short, opinionated summary. The goal is consistency across your team — every team member should be able to open any document and find what they're looking for in under a minute.

1. Document setup

An Onshape document holds tabs. Tabs hold Part Studios, Assemblies, and Drawings. The default impulse is to keep adding parts to one Part Studio until it has fifty of them and takes ninety seconds to regenerate. Don't.

What goes in the root document

  • One Part Studio per subsystem (drivetrain, intake, arm, etc.).
  • One Assembly that pulls those subsystems together into the full robot.
  • Drawings only for parts that get fabricated outside Onshape.

Naming: every tab. Every. Tab. Drivetrain beats Part Studio 4 in every scenario.

2. Sub-document setup

Once a subsystem grows past about forty parts, move it to its own document and link it back. Smaller documents load faster and let multiple teammates work in parallel without stepping on each other.

The pattern: a parent Robot document with a top-level Assembly that links derived parts from Drivetrain, Intake, and Arm sub-documents.

i
When to split

If regeneration takes more than 5–10 seconds, or if two people are blocked editing the same Part Studio, split. Earlier is better than later.

3. Layout sketch best practices

A layout sketch is a master sketch that drives downstream parts. Edit one set of dimensions, the whole subsystem updates. Without one, you're committing to manually fix every mate when something changes.

What goes in a layout sketch:

  • The chassis outline.
  • Motor positions.
  • Wheel positions and contact points.
  • Pivot axes for any moving subsystems.

What doesn't: per-part details. The layout sketch sets the skeleton; individual parts add flesh.

4. Part studio best practices

A Part Studio holds the parts of one subsystem. Two rules:

  1. One subsystem per Part Studio. The drivetrain gets its own. The arm gets its own. Don't mix.
  2. Variables, not magic numbers. Anything that might change goes in a variable. Define #chassisLength, #wheelDiameter, #frameThickness on day one.

Naming features

Default Onshape names (Sketch 4, Extrude 7) are useless. Renaming as you create takes five seconds; finding things later takes minutes if you didn't.

5. Assembly best practices

The top-level Assembly is where subsystems meet. Three rules:

  1. Use mate connectors. Add them to every part you'll mate to more than once.
  2. Prefer Fastened mates. Reach for Revolute or Slider only when something actually moves; over-flexible mates make assemblies fragile.
  3. Group related parts. Onshape's grouping keeps the Instances panel readable.

Self-review checklist

Before calling a document done, run this list with one teammate per item. Half of competition issues are visible in CAD if you look.

  • Does every Part Studio and Assembly tab have a meaningful name?
  • Do key dimensions reference variables, not hardcoded numbers?
  • Does increasing #chassisLength by 0.5″ update the document cleanly?
  • Can you remove the battery without taking the robot apart?
  • Does any moving part have at least 3 mm clearance to anything stationary?
  • Will this robot fit through a 24″ doorway with bumpers on?
!
Print this

Run the checklist out loud, with one person reading each item and another defending the design against it. You'll catch things silently waved past.
